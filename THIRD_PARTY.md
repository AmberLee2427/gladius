Gladius thanks the contributors to these direct runtime dependencies and optional extras.

| Project | Role | Principal project license |
| --- | --- | --- |
| [NumPy](https://github.com/numpy/numpy/blob/main/LICENSE.txt) | Array operations | BSD-3-Clause |
| [Astropy](https://github.com/astropy/astropy/blob/main/LICENSE.rst) | Coordinates, time and FITS | BSD-3-Clause |
| [ASDF](https://github.com/asdf-format/asdf/blob/main/LICENSE) | Scientific data serialization | BSD-3-Clause |
| [ASDF–Astropy](https://github.com/astropy/asdf-astropy/blob/main/LICENSE.rst) | Astropy object serialization | BSD-3-Clause |
| [GWCS](https://github.com/spacetelescope/gwcs/blob/main/licenses/LICENSE.rst) | Generalized coordinate transforms | BSD-3-Clause |
| [SciPy](https://github.com/scipy/scipy/blob/main/LICENSE.txt) | Scientific calculations | BSD-3-Clause |
| [Pydantic](https://github.com/pydantic/pydantic/blob/main/LICENSE) | Configuration validation | MIT |
| [PyYAML](https://github.com/yaml/pyyaml/blob/main/LICENSE) | YAML parsing and writing | MIT |
| [filelock](https://github.com/tox-dev/filelock/blob/main/LICENSE) | Run locking | MIT |
| [Astroquery (optional)](https://github.com/astropy/astroquery/blob/main/LICENSE.rst) | MAST access | BSD-3-Clause |
| [Roman datamodels (optional)](https://github.com/spacetelescope/roman_datamodels/blob/main/LICENSE) | Roman data format support | BSD-3-Clause |

The GUI exposes this information under Dependencies & acknowledgements, with a
review snapshot of license texts for the direct and optional dependencies. The
reviewed versions are identified in that snapshot. Installed versions and binary
wheel contents vary; preserve their accompanying license and copyright notices
when redistributing them. This list is not a complete transitive dependency audit.

The STScI package-template attribution is recorded in NOTICE.md and TEMPLATE.json.
