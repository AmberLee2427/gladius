# Reporting a security vulnerability

If you find a security vulnerability in Gladius, you can report it privately to
Amber at [malpas.1@osu.edu](mailto:malpas.1@osu.edu).

A useful report describes the problem, the affected version, its possible impact,
and how to reproduce it. A small example using synthetic data helps Amber
investigate without access to your files.

Reports should not include passwords, API tokens, or restricted Roman archive
data. Public issues and pull requests are not suitable places for vulnerability
details before Amber has had a chance to investigate and prepare a fix.
