# Gladius logo set

The supplied concept combines a downward gladius, a detector pixel grid, crop
corners, and the GLADIUS wordmark. These exports refine that concept.

## Intended use

- **Primary, dark:** package cover, dark slide backgrounds and README masthead.
- **Primary, light:** light documentation pages, slides and reports.
- **Compact emblem:** avatars and app tiles; omits the wordmark and simplifies the grid.
- **Single-colour study:** transparent dark-ink variant for exploring print use.

Use the primary logo large enough to preserve its grid and handle details.
Use the emblem at small sizes. At favicon sizes a further sword-only vector
reduction is preferable to shrinking the entire wordmark.

Leave at least one pommel diameter of clear space around the artwork. Do not
stretch, rotate, add shadows or place the full logo over a busy image.

## Production status

Created with the built-in image generation tool from Amber's supplied raster
concept. PNGs are raster artwork, not editable vector masters. Independently
generated variants can have small geometric differences; a final vector drawing
should unify them before print production or trademark use. Early transparent
colour exports showed noisy alpha edges and were excluded from the deliverable set.
The original concept is preserved in `reference/gladius-concept.png`.
